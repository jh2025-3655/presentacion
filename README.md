# datos de entrada 

1- cliente

2- Vehiculo

3- tarifa

4- Dias

5- Fecha 

6- seguro

7- GPS

8- tipo de entrega

# proceso

1- recibir los datos del cliente y del Vehiculo

2- Calcular el costo del alquiler multiplicado la tarifa diaria por la cantidad de dias 

3- sumar el costo del seguro completo ojo si fue selecionado

4- sumar el costo del GPS ojo si fue selecionado

5- Aplicar el descuento de 10% si el cliente es corporativo

6- agregar RD$ 500 si el Vehiculo si se entrega a domicilio 

7- calcular el ITBIS del 18% 

8- Sumar todos los valores para obtener el total a pagar 

9- mostrar los resultados en pantalla y registrar el alquiler en la tabla
